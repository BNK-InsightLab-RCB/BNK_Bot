**챗봇이 본 근거**
```
| 본 인 | 성 명 | (인) |
| 수입 인지 | 담 당 | 팀장 | 부점장 |
|  |  |  |  |
```

**판정 ○ 정당** — 약정서는 **계약 시 사람이 기입하는 양식**이라 조건란이 비어 있다.
문서 자체에 답이 없으므로 거부가 정답이다.
→ 평가셋이 상품명 목록에서 기계 생성되어 **서식류에도 상품 질문을 던진** 사례.

질문 자체가 이 문서로 답할 수 없다.

## ◎ [카드] 마이존체크카드상품 좀 알려줘 — **환각 차단 작동**

**챗봇이 본 근거**
```
myzone
## DuaPay
## 叶
myzone
```

**LLM이 생성하려 한 값** — `1`, `100`, `14.5` 등 수치 7건
**가드레일 판정** — 근거에 없는 수치 → **답변 폐기**
**사용자에게 전달된 답변** (16.4초)
> 제공된 자료에서 확인되지 않습니다.

**판정 ◎** — 근거가 11자뿐인데 LLM이 그럴듯한 수치를 만들어내려 했고, **숫자 검증이
이를 차단**했다. 프롬프트 지시가 아니라 코드로 강제한 통제가 실제로 작동한 사례다.
